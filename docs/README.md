# MobiGPT Documentation

This directory contains all documentation for the MobiGPT project.

## Documentation Structure

### Main Documentation
- **FEATURES.md** - Complete feature guide and user documentation
- **DEVELOPMENT.md** - Build instructions, troubleshooting, and developer guide
- **INTERACTIVE_TUTORIAL_GUIDE.md** - Interactive tutorial for new users
- **TUTORIAL_QUICK_REFERENCE.md** - Quick reference guide for common tasks
- **ABOUT_SETTINGS_SUMMARY.md** - Settings and configuration summary

### Archive
- **archive/** - Historical documentation and archived feature docs (40+ files)
  - Contains old implementation guides, fix summaries, and deprecated documentation
  - Kept for reference but no longer actively maintained

## Quick Links

For version history and changes, see [CHANGELOG.md](../CHANGELOG.md).

## Documentation Guidelines

When updating documentation:
1. Update the relevant main documentation file (FEATURES.md or DEVELOPMENT.md)
2. Keep the documentation concise and focused
3. Use clear headings and examples
4. Archive old documentation rather than deleting it
